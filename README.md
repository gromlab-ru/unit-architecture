# Unit Architecture

**Unit Architecture** — frontend-архитектура, которая организует код через слои, рекурсивные юниты, колокацию, публичные фасеты и направленные зависимости. Она помогает определить владельца ответственности, границу публичного API и допустимое положение кода в приложении.

## Установка AI skill

```bash
npx skills add gromlab-ru/unit-architecture
```

## Основная идея

Юнит — папка-владелец одной связной ответственности с хотя бы одним непустым публичным фасетом. Юнит может содержать любые выбранные командой файлы и сегменты, а также рекурсивно включать вложенные юниты.

Проект однозначно объявляет физические маркеры фасетов в своём архитектурном профиле. Папка с таким маркером всегда классифицируется как юнит, а ответственность и зависимости определяют, корректно ли он выделен.

Код появляется рядом с местом использования, остаётся у ближайшего владельца и поднимается к общей области только при расширении реальных потребителей. Framework-компонент, Provider, hook, store или тип файла сам по себе не создаёт архитектурную границу.

## Слои

| Слой | Ответственность |
|---|---|
| `app` | Запуск, маршруты и подключение готовых API |
| `compositions` | UI-проекции, связывающие готовые возможности |
| `domains` | Предметные ответственности, состояние и доменный UI |
| `infra` | Технические возможности без предметного смысла |
| `ui` | Универсальные визуальные возможности |
| `shared` | Детерминированный фундамент |

Слой определяет архитектурную роль и допустимые направления зависимостей, но не внутреннее устройство юнита. Пустые слои не создаются.

## Ключевые свойства

- Один владелец каждой самостоятельной ответственности.
- Колокация кода у ближайшего владельца.
- Свободная внутренняя структура юнита.
- Один логический публичный API с минимально необходимыми фасетами.
- Однозначное обнаружение юнитов по объявленным маркерам фасетов.
- Scope-aware публичность вложенных юнитов.
- Импорты между юнитами только через фасеты.
- Направленный ацикличный граф зависимостей.
- Вертикальные домены, владеющие сценарием вместе с состоянием, UI и адаптацией источников.

## Разработка

Требуется Node.js 20 или новее.

```bash
npm run build:skill
```

Исходный файл skill находится в `src/skills/unit-architecture/SKILL.md`. Сборка создаёт устанавливаемый каталог `skills/unit-architecture/` и полностью копирует `docs/` в `skills/unit-architecture/reference/docs/`.

`docs/` остаётся источником документации. Собранный reference и `skills/unit-architecture/SKILL.md` не редактируются вручную.
